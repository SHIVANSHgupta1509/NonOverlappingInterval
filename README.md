# Non-Overlapping Intervals Visualizer

A small React + Vite app for teaching the greedy solution to the Non-Overlapping Intervals problem.

## Features
- Live timeline as intervals are typed
- Add interval controls
- Minimum removals and intervals to keep/remove
- Greedy walkthrough sorted by end time
- Responsive layout for desktop and mobile

## Run locally
Install Node.js, then run:

```bash
npm install
npm run dev
```

## Build for deployment
```bash
npm run build
```

## Deploy on Vercel
1. Create a GitHub repository and upload these project files.
2. Sign in to Vercel and import the repository.
3. Vercel should detect Vite automatically.
4. Use `npm run build` as the build command and `dist` as the output directory.
5. Deploy. Share the generated `*.vercel.app` URL.

The project is a static front-end app; no database or environment variables are needed.
